# 💈 Barbearia João Batista - Mamanguape/PB

> **A excelência em cada corte no centro de Mamanguape.**
> Este site foi desenvolvido para facilitar o acesso dos clientes aos nossos serviços, horários e localização.

---

## 🚀 Sobre o Projeto
Um site moderno, rápido e totalmente focado na experiência do usuário via celular.

### ✨ Funcionalidades:
- 📍 **Localização Integrada:** Mapa configurado para facilitar a chegada do cliente.
- ⚡ **Papo Reto:** Aviso claro de que trabalhamos por **Ordem de Chegada**.
- 📱 **Responsivo:** Design que se adapta perfeitamente a qualquer tela.
- 💬 **Botão de Contato:** Link direto para o WhatsApp para tirar dúvidas.

## 🛠️ Tecnologias
- **HTML5** e **CSS3**
- **JavaScript** (para ícones e integração)
- **Google Maps Iframe** (Localização gratuita e estável)

## 📌 Diferencial
O site elimina a confusão de agendamentos, deixando claro que o foco é o atendimento por fila, respeitando o tempo de cada cliente.
